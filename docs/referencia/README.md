# Referências visuais

Modelos em HTML single-file, para abrir no navegador e usar como referência de layout e animação. Não fazem parte do código do CRM.

- `modelos_interacao.html`: catálogo de interações (abas deslizantes, teclas mecânicas, luz que segue o mouse, barras de ícones, menu em leque).
- `crm_modelo_pc.html`: modelo de organização do CRM para PC (menu lateral, funil kanban, lista, painel, gaveta do lead, paletas de cor).
